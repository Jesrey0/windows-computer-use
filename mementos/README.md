# Mementos

Small artifacts created *through Windows Computer Use itself* and kept as historical markers for the release that made them possible.

Each entry records the WCU version, the interaction path used to create it, and enough provenance to make the artifact meaningful later. These are not product fixtures or test assets; they are release-era keepsakes.

| 0.4.0 | [Stillwater Relay](./0.4.0/stillwater-relay.md) | Layered landscape, custom colors and native Paint export |
